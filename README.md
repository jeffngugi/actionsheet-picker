# actionsheet-picker

Searchable, hierarchical, infinite-scrolling single/multi action-sheet picker for React Native. Zero native dependencies.

## Installation


```sh
npm install actionsheet-picker
```


## Usage


```js
import { multiply } from 'actionsheet-picker';

// ...

const result = multiply(3, 7);
```
